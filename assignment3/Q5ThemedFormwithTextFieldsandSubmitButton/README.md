## Q5 Themed Form with TextFields and Submit Button

This assignment uses the following: 
- Build a login form (username + password fields).
- Style the fields using Material 3 theme colors and typography.
- Add validation: show error text if fields are empty when submitting.

## Getting Started
Building & Running
Clone the repository (if applicable): git clone https://github.com/javeriajalil889/501-mobile-app.git
cd into the directory:  CS501_MOBILE_APP_MAIN/assignment3/Q5ThemedFormwithTextFieldsandSubmitButton

Open the project in Android Studio.
Let Gradle sync.
Run on an emulator or device.
